## 🚀 Sobre o Projeto
Este projeto é um clone simplificado do Twitter, desenvolvido durante o curso da Rocketseat, utilizando React, TypeScript, e Vite. O objetivo principal foi consolidar os conhecimentos em desenvolvimento frontend, incluindo roteamento, gerenciamento de estado e manipulação de eventos.

## 📝 Funcionalidades Principais
<li>Postar Tweets: Permite criar novos tweets que são adicionados à timeline.
<li>Roteamento: Navegação entre diferentes páginas como a timeline e a visualização detalhada de tweets.
<li>Componentização: Uso de componentes reutilizáveis como Header, Separator e Tweet para estruturar a interface.

## 🛠️ Tecnologias Utilizadas
<li>React: Biblioteca para construção da interface.
<li>TypeScript: Para tipagem estática e maior confiabilidade no código.
<li>Vite: Ferramenta para build e desenvolvimento rápido.
<li>React Router: Gerenciamento de rotas.
<li>CSS: Estilização personalizada com classes.

## 📚 Estrutura de Aprendizados
1. Gerenciamento de Estado
<li>Utilização do useState para armazenar e atualizar a lista de tweets.
<li>Resetar o campo de entrada após o envio de um tweet. <br>
2. Manipulação de Eventos
<li>Captura de eventos de formulário com FormEvent para evitar o comportamento padrão de recarregar a página ao enviar um formulário.
<li>Uso de KeyboardEvent para implementar atalhos de teclado. <br>
3. Componentização
<li>Criação e uso de componentes reutilizáveis:
<li>Header: Exibição do título da página.
<li>Separator: Linha divisória para separar seções.
<li>Tweet: Exibição de cada tweet na timeline. <br>  
4. Roteamento com React Router
<li>Configuração do roteamento com createBrowserRouter:
<li>Página inicial (Timeline). <br>
<li>Página de visualização de tweets específicos (Status).
<li>Utilização do componente Default como layout base para as rotas. <br>
5. Formatação e Estilização
<li>Estilo customizado em Timeline.css para garantir uma aparência agradável e responsiva.
<li>Exibição do avatar do usuário e formulário com placeholders intuitivos.
